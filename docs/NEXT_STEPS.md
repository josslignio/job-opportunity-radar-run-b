# Next steps after V0

## V0 acceptance gate

- offline tests green;
- one bounded real network run;
- at least three valid sources across the three personas;
- no cross-project contamination;
- report manually reviewed;
- false positives and false negatives logged.

## V1 — useful daily digest

- 25–50 curated company boards;
- source-health history;
- first-seen vs seen-before labels;
- explicit “apply today” urgency;
- report archived daily;
- manual status changes: reviewed, ignored, prepared, applied.

## V2 — application copilot

For each human-selected role only:

- choose one CV;
- generate a tailored headline;
- propose three CV bullet edits;
- generate a concise cover note;
- generate a recruiter message;
- flag every statement requiring verification.

No submission.

## V3 — response and follow-up loop

- read-only Gmail matching of replies;
- follow-up due dates;
- source/persona conversion statistics;
- feedback-driven scoring calibration.

## V4 — semi-automation

Only after 20–30 reviewed applications:

- prefill simple forms;
- stop on every ambiguous question;
- require human confirmation before submission;
- store a full application evidence bundle.
